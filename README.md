# 🏀 SPORTS LIVE

**一个基于 WebView 封装的 Android 体育直播浏览器。**

本项目将第三方体育直播网站封装为 Android APK，提供更方便的移动端访问体验。

## ✨ 功能特点

- 📺 内置第三方体育直播网页
- 📱 Android APK 安装使用
- 🖥️ 支持视频全屏播放
- 🎨 浅色风格界面
- 🚀 针对移动端浏览体验进行优化

## 🛠️ 技术说明

- 开发语言：Kotlin
- 开发工具：Android Studio
- 核心技术：Android WebView
- 项目类型：网站封装 APK
